About this program

intersteller is a web application built with HTML that allows users to explore detailed information about the planets in our Solar System By clicking on any planet's card. view key facts such as diameter, number of moons, distance from the Sun, and average temperature, and save their favorite planets after creating an account. This project was developed as my final project for Harvard University's CS50 course(ANOTHER VERSION), HTML, CSS, and user authentication.
